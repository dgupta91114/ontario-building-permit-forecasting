# APA 7 and Reporting Notes

The final paper—not the repository README—remains the authoritative APA 7 submission. Use the repository as evidence of transparent and reproducible analysis.

- Cite Statistics Canada tables by agency, year, table title and number, and DOI.
- Cite the Bank of Canada Valet API and identify series V39079 in the method section.
- Number and title every table and figure imported into the paper.
- Add a figure note when an image is generated from the author's analysis of government data.
- Report exact *p* values to three decimals, using *p* < .001 when appropriate.
- Italicize statistical symbols in the paper: *M*, *SD*, *n*, *p*, *F*, *t*, and *r*.
- Distinguish prespecified analyses from sensitivity analyses.
- Do not treat forecast accuracy as causal evidence.
- Document the final Git commit hash and data-download timestamp in the final capstone appendix.
