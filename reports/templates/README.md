# Report Template Working Area

The historical draft generator uses the supplied interim-report template working copy. The final submission generator uses `QM_640_Final_Report_Template.docx`, copied from the user's `Final report details` folder. The user-supplied 40-page requirement supersedes the final template's legacy interim-report length sentence. See `../final/README.md` for the final requirements and rubric map. The original templates and prior submission artifacts remain unchanged.
